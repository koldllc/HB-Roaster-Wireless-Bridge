# Artisan 软件配置与四路曲线详解

本文档详细说明在 **Artisan Roaster Scope** 中配置 **HB Roaster Wireless Bridge** 无线桥接的所有参数细节。

如果你之前已经通过有线物理 USB 串口连接并保存过 `.aset` 配置文件，**你绝大多数设置都是现成的，只需要修改「端口」一处即可**。在新电脑或全新安装 Artisan 时，请参考以下全量设置。

---

## 1. 端口设置 (Config -> Ports)

这是从有线切换为无线**唯一必须修改**的地方。

1. 打开 Artisan，点击顶部菜单：**配置 (Config)** -> **端口 (Ports)**。
2. 在弹出窗口中，找到 **Comm Port（通信端口）** 输入框：
   - 选中并删除原先的物理端口（如 `/dev/cu.usbserial-110`）。
   - **直接手动打字输入**：
     ```text
     /tmp/hb_roaster
     ```
     *(注：Artisan 的端口选择框支持手动输入自定义路径)*
3. 其他串口通信参数：
   - **波特率 (Baud Rate)**：`115200`（虚拟串口底层为系统内存管道，任意波特率均通畅）
   - **数据位 (Byte Size)**：`8`
   - **校验位 (Parity)**：`None (N)`
   - **停止位 (Stopbits)**：`1`
   - **超时时间 (Timeout)**：`0.4` 秒或 `0.5` 秒
4. 点击右下角 **OK** 保存。

---

## 2. 设备类型核对 (Config -> Device)

确认 Artisan 当前使用的是针对 HB Roaster 的专用驱动：

1. 点击菜单：**配置 (Config)** -> **设备 (Device)**。
2. 主设备（Device）：选择 **HB Model S**（或者 **HB Standard**）。
   - 内部设备编号对应 `126 ARC_BTET`。
3. 切换到 **Extra Devices（附加设备）** 标签页：
   - 第一行附加设备：选择 **+ARC MET/IT**（设备号 `127`），名字分别命名为 `Exhaust` 与 `Inlet`。
   - 第二行附加设备：选择 **+HB AT**（设备号 `128`，环境温，可选）。
4. 勾选需要显示的曲线：
   - 勾选 `Curve` 复选框以在图表上绘制曲线。
   - 勾选 `LCD` 复选框以在主界面右侧 LCD 面板中显示大字温度。

---

## 3. 四路温度通道与硬件映射关系

HB 烘焙机内置 4 路高精度测温探针，无线桥接应用已将其与 Artisan 的标准通道进行了精准对齐：

| 硬件物理通道 | 探针测量位置 | Artisan 设备驱动 | Artisan 曲线名称 | 建议颜色 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **通道 3** | **豆温 (BT)** | `ARC_BTET` | **BT** | 亮绿色 (`#00D084`) | 锅炉内部接触咖啡豆的温度，计算 RoR 升温率的核心 |
| **通道 4** | **环境/炉温 (ET)** | `ARC_BTET` | **ET** | 鲜红色 (`#FF4757`) | 锅炉内部空气/环境温度 |
| **通道 1** | **出风温/排烟废气 (Exhaust)** | `+ARC MET/IT` | **Exhaust** | 天蓝色 (`#38BDF8`) | 银皮收集筒/排烟通道测得的废气温度 |
| **通道 2** | **进风温 (Inlet)** | `+ARC MET/IT` | **Inlet** | 明黄色 (`#FBBF24`) | 热风加热管/热源送入滚筒前的热风温度 |

## 4. 采样率与曲线平滑度建议 (Config -> Sampling)

为了获得最平滑、无延迟且 RoR 升温率曲线不过度抖动的烘焙曲线，建议核对采样设置：

- **采样周期 (Sampling Interval)**：设置为 **`1.0` 秒**。
  - *原因：HB 烘焙机底层的固件遥测刷新率恒定为 1 Hz（1 秒 1 次）。将 Artisan 的采样周期设为 1.0 秒能做到与硬件节奏绝对同步，延迟最低。*
- **过采样 (Oversampling)**：建议 **关闭 (取消勾选)**。
- **自动丢弃重复值 (Drop Duplicates)**：建议 **勾选**，阈值设为 `0.1`。
- **升温率计算平滑 (RoR Delta Span)**：建议设置为 **`12` 秒 ~ `15` 秒**，能有效过滤测温噪点并清晰反映真实的温度变化速率。

---

## 5. 控制指令支持 (Artisan 按钮/滑块 - 可选)

无线桥接应用内置支持监听 Artisan 发送的控制指令：

- **加热控制 (`OT1`)**：若在 Artisan 中绑定了加热事件或滑块（Duty），输出值大于 0 时，应用会自动向烘焙机下发开启加热指令。
- **排风降温 (`OT2`)**：若绑定了排风风扇，输出大于 0 时自动下发排风降温指令。
- **搅拌控制 (`IO3`)**：控制冷却盘搅拌臂启停。

*(通常情况下，也可直接在 HB Roaster Wireless Bridge 菜单栏面板上直观轻触控制机身开关与加热状态)*。
